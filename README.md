# 🌌 NebulaCube

NebulaCube is an immersive 3D space visualization experience featuring a continuously rotating cube containing distant galaxies and cosmic imagery.

The project is inspired by humanity’s curiosity about the unknown universe and represents visuals captured from far regions of space that humans have not yet reached.

Built with modern web technologies, NebulaCube combines futuristic design, motion, and interactive visuals to create a cinematic cosmic experience directly in the browser.

---

## ✨ Features

- 🌌 Continuously rotating 3D cube
- 🪐 Galaxy-inspired immersive visuals
- 🎨 Futuristic dark-themed interface
- ⚡ Smooth animations and transitions
- 📱 Responsive design for multiple devices
- 🚀 Interactive space-inspired experience

---

## 🛠 Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Vercel

---

## 🎯 Project Vision

NebulaCube explores the idea of transforming deep-space imagination into an interactive digital experience.

The project aims to make users feel as if they are observing mysterious galaxies floating inside a futuristic cosmic structure — representing regions of the universe beyond current human exploration.

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/sajanbodele/NebulaCube.git
```

Go to the project folder:

```bash
cd NebulaCube
```

Install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

---

## 🌍 Deployment

Deployed using Vercel.
